# Navill 计划书 v0.7（待审核，2026-10-14）

> 标【已定】为 Rei 已确认；标【建议】为待审核的默认方案，审核通过即定稿。

## 1. 目标
Navill 是一个 Chrome / Edge 扩展：**一次性**导入浏览器书签，按「工作区 → 抽屉 → 书签」三层重新组织，之后作为独立的书签导航使用。与浏览器书签**不双向同步**；Navill 自身数据通过 Google Drive 在多设备间同步。

## 2. 术语
| 术语 | 含义 |
|---|---|
| 工作区 Workspace | Navill 内部概念，最上层 |
| Edge 工作区节点 | 浏览器书签树根下，与 `bookmark_bar` / `other` / `mobile` 同级、**无标题**的其余节点；扩展 API 可读【已定】。代码中命名 `edgeWorkspaceNode`，与 Navill 工作区严格区分 |
| 抽屉 Drawer | 工作区内的书签分组，由文件夹拍平而来 |
| 分身 | 书签的**引用**，出现在另一个抽屉中；标题、URL 永远跟随原书签【已定】。术语固定为「分身」，不改名 |
| 分身书签组 | 把某个抽屉的**全部书签**挂载到另一个抽屉，可跨工作区，实时引用【已定】 |
| 待整理 | 系统工作区，收纳散放和未分组书签【已定】 |
| 场景 Mode | 一组可见性规则：哪些工作区 / 抽屉在该场景下显示，以及是否显示 18+ 内容【已定】。代码中命名 `Mode` |
| 标签 Tag | 仅作用于书签；一个书签可有 0 到多个不重复标签【已定】 |

## 3. 导入与拍平规则
- 每个 **Edge 工作区节点** → 一个工作区，名称取其**第一个子节点的标题**【已定】；标题为空或节点为空时回退为「Edge 工作区 N」，预览中可改名。第一个子节点本身照常导入。
- **书签栏下每个顶级文件夹** → 一个工作区。
- 工作区内所有次级及更深的文件夹 → **全部拍平**为该工作区下的独立抽屉；抽屉名带路径前缀（如「前端 / React」）避免重名，设置中可改为只显示末级名。
- 书签栏根目录的**散放书签** → 工作区「待整理」【已定】。顶级文件夹（或 Edge 工作区节点）下直接放的**未分组书签** → 留在该工作区**顶层**（显示在抽屉上方），不进「待整理」【已定，2026-10-14】。「待整理」不可删除，固定排在末尾，内部按来源分抽屉（如「书签栏」「其他书签」）【已定】。
- 空文件夹跳过。
- 「其他书签」「移动设备书签」：默认不导入，预览页可勾选；勾选后规则同书签栏【已定】。

### 首次导入流程
1. 欢迎页说明「只导入一次，之后与浏览器书签互不影响」。
2. 读取 `chrome.bookmarks.getTree()`，预览：将生成 N 个工作区、M 个抽屉、K 个书签；可取消勾选文件夹、可改工作区名。
3. 确认后写入本地库，记录 `importedAt` 与浏览器类型。
4. 此后不监听浏览器书签事件，Navill 的改动也不写回浏览器。

### 无书签数据的情况【已定需覆盖，方案为我定】
- 浏览器里一个书签都没有（或全部取消勾选）时，跳过预览，欢迎页给出四个起点：
  1. **从 Google Drive 恢复**：登录后拉取已有的 Navill 同步数据（换新设备的常见情况，放在第一位）
  2. **导入文件**：Navill JSON 备份或标准书签 HTML
  3. **新建第一个工作区**：输入名称即可开始
  4. **先跳过**：直接进入空的主界面
- 无论哪种，系统工作区「待整理」始终存在，工具栏弹窗的「收藏当前页」默认放进「待整理」，所以空库也能直接开始收藏。
- 空状态界面：没有工作区时显示新建引导；空工作区显示「添加书签 / 新建抽屉 / 从其他工作区整理过来」；空抽屉显示可拖入提示；搜索无结果给出「在全部工作区中搜索」；「待整理」为空时显示「都整理好了」。
- 之后浏览器有了书签，可随时在设置中「重新导入」。
- 同步：本地为空、云端有数据时直接拉取，不会出现空数据覆盖云端；本地和云端都为空时不创建文件，等第一次改动后再上传。

### 重新导入【已定】
设置中提供「重新导入」，默认**追加并按 URL 去重**；另可选「覆盖」（需二次确认并先自动备份）。

## 4. 数据模型
```
Workspace  { id, name, emoji?, color, description?, order, viewMode: 'icon'|'row'|'tile'|'bento', source: 'bookmark_bar'|'other'|'mobile'|'edge_workspace'|'manual'|'inbox', sourceNodeId?, createdAt }
Drawer     { id, workspaceId, name, path: string[], order, height?（内容区高度，底部拖拽手柄调整，空=自适应；collapsed 已停用）, viewMode?: 'icon'|'row'|'tile'|'bento', sortMode?: 'manual'|'name-asc'|'name-desc'|'clicks-asc'|'clicks-desc' }  // viewMode 为空时继承工作区
Bookmark   { id, url, title, faviconUrl, note?, archivedAt?, openCount, lastOpenedAt?, createdAt, updatedAt }
OpenEvent  { id, bookmarkId, placementId, openedAt }   // 每次打开一条时间戳记录
Placement  { id, bookmarkId, workspaceId, drawerId: string|null, order, isAlias }  // drawerId 为 null = 工作区顶层无抽屉书签；多个 placement = 分身
AliasGroup { id, sourceDrawerId, targetDrawerId, order, createdAt } // 目标抽屉渲染时展开源抽屉全部书签
Mode       { id, name, builtin: 'default'|null, order, hiddenWorkspaceIds: string[], hiddenDrawerIds: string[], showAdult: boolean, createdAt }
Tag        { id, name, builtin: 'adult'|'favorite'|'todo'|null, order, createdAt }
// 另：Workspace / Drawer 增加 adult?: boolean（18+ 标记）；Bookmark 增加 tagIds: string[]（不重复）
```
- 书签字段【已定】：名字、URL、图标；并统计**使用次数**及**每次使用的时间戳**。只统计从 Navill（新标签页 / 弹窗 / 搜索 / 抽屉全部打开）发起的打开；分身与原书签是同一实体，计数合并，`OpenEvent.placementId` 记录从哪个位置打开。
- 统计随同步上传；`OpenEvent` 可在设置中清空。
- 存储：IndexedDB（Dexie）存数据，`chrome.storage.local` 存设置。
- 分身书签组需防循环挂载（A→B→A，或更长链）。
- 场景、标签定义随同步上传；**当前场景**存 `chrome.storage.local`，按设备各自记，不同步【已定】。

## 5. 界面
- 入口【已定】：**替换新标签页**（完整界面）+ **工具栏弹窗**（快速搜索、切换工作区、收藏当前页到指定抽屉）。不做侧边栏。
- 新标签页：工作区导航 + 主区抽屉卡片，可折叠、拖拽排序、书签跨抽屉拖拽、抽屉一键全部打开。
- **工作区导航布局**【已定】：两种，可在设置中切换【建议：全局设置，默认侧边栏】
  - 侧边栏：在左侧纵向排列，可收缩成只显示图标的窄栏（收缩状态按设备记住）
  - 顶部横铺：在顶栏横向排列，超出宽度时左右滚动（滚轮 / 触控板横滑 / 两端箭头）
  - 两种布局都支持拖拽排序工作区
- **工作区显示方式**【已定】：只显示图标 / 只显示名称 / 图标 + 名称【建议：全局设置，默认图标 + 名称】；侧边栏收缩时强制只显示图标。没有 emoji 的工作区用名称首字配工作区颜色作图标【建议】。悬停显示说明（tooltip）。
- **工作区右键菜单**【已定】：编辑；另含「标记为 18+ / 取消 18+」（见下）、删除【建议】。
  - 编辑：名称、图标（emoji 选择器）、颜色、说明（一句话，用作 tooltip，上限 50 字【建议】）。
  - 颜色：从一组预设色中选，新建 / 导入时自动轮流分配默认色【建议】；颜色用于图标底色与选中态。
  - 「待整理」可编辑图标、颜色、说明，名称与删除不可改【建议】。
- 全局搜索：标题 + URL + 备注；`/` 聚焦，回车打开，键盘全程可用。
- **抽屉标题栏**【已定】（从右到左）：
  - 最右 **ellipsis（⋯）菜单**，按可用空间自动向下或向上展开：创建分身（即把本抽屉作为分身书签组挂到其他抽屉）、解散、删除、打乱
    - 解散：删除抽屉本身，书签移到所在工作区顶层【已定】
    - 删除：抽屉连同其中书签一起删除，需二次确认；被删的若是原书签，其分身一并处理的方式同 6.3
    - 打乱：把抽屉内书签随机重排一次，并将排序切回「手动」
  - 其左 **排序**：名称升序 / 降序、点击次数升序 / 降序；另保留「手动」（拖拽后自动切回）【已定】
  - 再左 **视图模式**：图标、行、平铺、bento
  - **双击标题**原地改名，回车确认、Esc 取消
- **右键菜单**【已定】
  - 书签：编辑、分身到…、移动、删除、归档
  - 分身：分身到…、移动、删除（分身不可编辑、不可归档，因为标题和 URL 跟随原书签）
  - 编辑：改名称、URL、图标、备注；改动同步到全部分身
  - 分身到… / 移动：弹出「工作区 → 抽屉（或顶层）」选择器，与「整理」共用
  - 删除原书签时提示「仅删此处 / 删除原书签及全部分身」；删除分身只删这一处
- **归档**【已定】：归档后的书签及其全部分身从各工作区隐藏，统一进「归档」视图（侧栏底部入口），可恢复到原位置或彻底删除；默认搜索不含归档，可勾选「包含归档」；使用统计保留。
- **视图模式优先级**【已定】：工作区可设统一视图模式；抽屉单独设置的视图模式优先于工作区设置，抽屉可「跟随工作区」恢复继承。
- 工作区顶层的无抽屉书签默认显示在最上面，抽屉在其下【已定】。
- **整理**【已定】：点击「整理」进入多选模式，可跨工作区、跨抽屉勾选书签，选好后可执行两种操作：①「移动到…」批量移到指定工作区的指定抽屉（也可选该工作区顶层）；②「创建分身到…」批量为它们在指定工作区的抽屉中创建分身（原位置不变）【已定】。移动分身只移动该处位置，不影响原书签和其他分身；分身书签组挂载进来的书签不可在目标处移动（需到源抽屉操作）【已定】。
- 分身与挂载书签带角标，悬停显示「源自 工作区 / 抽屉」。
- **场景切换**：新标签页顶栏与工具栏弹窗都有场景切换器，显示当前场景名【建议】。
- **18+ 标记**【已定】：工作区、抽屉右键菜单增加「标记为 18+ / 取消 18+」；书签的 18+ 通过标签设置（见 6.5）。
- 书签右键菜单增加「标签…」：勾选多个标签，可就地新建标签【建议】；「整理」多选模式也可批量加 / 去标签【建议】。
- 主题：浅色 / 深色 / 跟随系统，首屏无闪烁；phosphor 图标（Kumo 配套）；中文 UI。

## 6. 设置
### 6.1 通用与外观【已定 2026-10-15：拆成两个 tab】
- 通用：默认进入的工作区（上次 / 固定）、书签打开方式（当前标签 / 新标签 / 后台）、网站图标授权与缓存、新标签页接管
- 外观：主题、卡片风格；工作区导航位置（左 / 右 / 顶 / 底）、工作区显示（图标 / 名称 / 图标 + 名称）、工作区图标风格；抽屉名显示（完整路径 / 仅末级）、抽屉标题栏（悬停显示 / 始终显示）
- 导入 / 重新导入；导出 Navill JSON 备份；导出标准 Netscape 书签 HTML

### 6.2 同步【已定：Google Drive】
- 存储位置：用户 Google Drive 的 **appDataFolder**（隐藏应用目录，不出现在文件列表，计入配额但体积很小）。
- 权限：仅 `https://www.googleapis.com/auth/drive.appdata`（官方列为非敏感 scope，只需基础 OAuth 验证）。
- 授权：`chrome.identity.launchWebAuthFlow` + Google OAuth（Edge 不支持 `getAuthToken`，此法两端通用）；token 过期先 `prompt=none` 静默续期，失败再弹窗。
- Google Cloud 建一个 Web 类型 OAuth 客户端，Chrome 与 Edge 扩展 ID 不同，各登记一个回调 `https://<extension-id>.chromiumapp.org/`。
- **本地优先 + 批量同步**【已定原则，方案为我定】：所有读写只走本地 IndexedDB，界面从不等网络；同步是后台批量任务。
  - 本地变更队列 `Outbox { id, entity, entityId, op, updatedAt }`：结构类改动（工作区 / 抽屉 / 书签 / 分身 / 挂载）写本地同时记一条，同一实体多次修改合并为一条。
  - 使用统计不进队列：`OpenEvent` 只追加到本地，`Bookmark.openCount / lastOpenedAt` 本地即时更新。
  - 触发上传：`chrome.alarms` 每 15 分钟检查一次，有待传内容才上传；另外在浏览器启动、设置页点「立即同步」时触发。不在每次改动时上传。
  - Drive 文件布局（appDataFolder）：`state.json`（全量结构快照，含各书签累计计数，gzip）；`events/<deviceId>-<YYYY-MM>.jsonl.gz`（各设备按月追加的打开记录，每台设备只写自己的文件，天然无冲突）。
  - 拉取：启动时与每次上传前先比对 Drive 文件的 `modifiedTime`，有变化才下载合并；计数 = 各设备事件合并去重后重算。
  - 失败退避（1 → 5 → 15 分钟），离线时只积压本地队列。
- 同步：开关、频率（默认 15 分钟，可选 5 / 15 / 60 分钟或仅手动）、手动立即同步、冲突策略（默认按条目合并，`updatedAt` 新者胜）、上次同步时间与状态；失败时显示 HTTP 状态码及中文释义（如「401 未授权」「429 请求过多」）。
- 退出登录 / 删除云端数据。

### 6.3 分身
- 分身：任意书签可「创建分身」到其他抽屉；删除时可选「仅删此处 / 删除原书签及全部分身」。
- 分身书签组：在抽屉菜单「挂载到…」选择目标抽屉（可跨工作区）；可解除挂载。
- 管理页：列出所有分身与分身书签组、各自引用位置；可「转为独立书签」（解除引用，复制一份）。

### 6.4 场景【已定】
- 设置中单独一个「场景」tab。预设：默认、工作、居家、演讲、借用。
- 「默认」场景显示全部工作区与抽屉，可见性不可编辑，不可删除、不可改名【已定】；其 18+ 开关仍可切换【建议】。
- 其他场景可改名、删除，用户可新增；每个场景勾选其中可见的工作区与抽屉（树形列表，工作区隐藏则其下抽屉一并隐藏）。
- 每个场景有「显示 18+」开关：关闭时隐藏标记 18+ 的工作区、抽屉，以及带 18+ 标签的书签（含其分身和挂载副本）。预设场景默认均为关闭【建议】。
- **新建工作区 / 抽屉的可见性**【已定】：默认在所有场景可见（场景里存的是隐藏名单）。若当前处于「默认」以外的场景，新建时提示用户选择「仅当前场景可见」或「所有场景可见」。
- 搜索、弹窗、「全部打开」均只作用于当前场景可见的内容；被隐藏的内容在「默认」场景始终可见。
- 删除场景时，若它是某设备的当前场景，该设备回到「默认」。

### 6.5 标签【已定】
- 设置中单独一个「标签」tab。内置三个：18+、收藏、待办，不可改名、不可删除；用户可新增、改名、删除自定义标签。
- 标签只针对书签，一个书签可有 0、1 或多个不重复标签；分身显示原书签的标签（标签属于书签本身）。
- 删除自定义标签时从所有书签上移除，需确认。
- 搜索支持按标签筛选（如输入 `#待办`）【建议】。

### 6.6 关联链接【已定 2026-10-14，Rei 要求从简】
- 一个书签可带多条关联链接（GitHub、文档、社交账号等），`Bookmark.links?: { url; title? }[]`，随书签同步；分身共享。
- 有关联链接时图标右上角显示小红点；点击弹出列表（主链接在首位），一列最多 6 条，更多分列；弹层自动选择左右上下的位置（Kumo Popover）。
- 不做类型识别、不做合并。子条目可在编辑书签对话框里添加、修改、删除；弹层里悬停可直接删除，底部「添加」「编辑」打开编辑对话框。
- 打开关联链接计入该书签打开次数；搜索匹配关联链接；HTML 导出把关联链接作为「主书签名 · 名称」的普通书签跟在后面。

### 6.7 高清网站图标【已定 2026-10-14】
- 按域名抓取一次，缩到 64px WebP 存 IndexedDB `icons` 表（每个约 1–3KB），只存本机、不同步；成功 30 天、失败 7 天后重试。
- 来源顺序：网页自带 apple-touch-icon / manifest / svg（需在 设置 → 通用 授权可选权限「访问所有网站」）→ icon.horse（识别并跳过它的字母占位图）→ Google s2 sz=128；小于 48px 视为不清晰。都失败时用浏览器自带 favicon。
- 用户在编辑书签里填的图标地址优先。设置里可「重新获取」清空缓存。

### 6.8 新建 / 编辑书签自动补全【已定 2026-10-14】
- 名称和 URL 输入框都可补全：按关键词搜本机浏览记录（chrome.history，可选权限 history，对话框里点「开启」授权），按访问次数排序取前 8 条。
- 选中一条同时回填 URL 和名称（在 URL 框选中时，已填的名称保留）。新建书签由单行提示框改为「名称 + URL」对话框。

### 6.9 工作区上限与双图标【已定 2026-10-14】
- 最多 30 个工作区（含「待整理」）。满了「新建工作区」提示已满；导入预览超出部分默认不勾选，勾选数不能超过剩余名额。同步合并不受限。
- 工作区存两套图标：`emoji`（最多 2 个）和 `lucide`（Lucide 图标名）。设置 → 外观「工作区图标」切换 Emoji / 线性图标（按设备）；所选风格没设图标时显示首字。编辑工作区里两种分别设置。

### 6.10 抽屉归档【已定 2026-10-14】
- 抽屉 ⋯ 菜单「归档」：抽屉（含其挂载出去的分身书签组）在工作区、搜索和移动目标里隐藏；「归档」视图新增「抽屉」分组，可恢复或删除。搜索勾「包含归档」时能搜到。

### 6.11 快捷键、提醒与日志【已定 2026-10-15】
- 快捷键（设置 → 快捷键，只读列表）：⌘S / Ctrl+S 立即同步，上次同步不到 3 分钟或没有待上传改动时跳过并提醒，未登录或未开启同步也提醒；⌘L / Ctrl+L 与 / 打开搜索。在页面捕获阶段处理；焦点在地址栏时 ⌘L 由浏览器处理，无法接管。
- 提醒（设置 → 提醒，按设备存 storage.local）：自建轻量 toast（Kumo Toasty 不支持位置）。位置 6 种（默认右下），样式 简洁 / 彩色 / 深色 / 胶囊，可预览；开关：同步完成、新建 / 修改 / 删除 / 移动书签，默认全开。书签提醒由日志事件驱动，批量操作合并成一条；⌘S 跳过等直接反馈总是显示。同步完成只对本页发起的同步提醒，后台定时同步不提醒。
- 日志：Dexie `logs` 表（v4）。store 层用 `logged()` 记录工作区 / 抽屉 / 书签的新建、改名、编辑、删除、移动、归档、恢复、分身；嵌套操作只记最外层一条；另记新设备首次安装（浏览器 · 系统，取自 UA）与登录 Drive。本机始终记录。
- 同步可选数据：核心数据始终同步；「日志」开关默认关，开启后按设备、按月追加上传 `logs/<设备>-<月>.jsonl.gz`，下载其他设备文件按 id 合并。同步页「查看日志」显示最近 500 条。

### 6.12 导航调整【已定 2026-10-15】
- 「新建工作区」「归档」移入 ⋯ 菜单（搜索 · 场景 | 新建工作区 · 整理 · 归档 | 同步 · 设置），侧边栏底栏与顶部条右端不再放这两个按钮。
- 顶部工作区条：溢出一侧渐隐遮罩（mask-image），悬停时浮现小箭头（半透明，淡入 + 位移 200ms），平滑滚动，纵向滚轮转横向，选中的工作区自动滚入视野；尊重 prefers-reduced-motion。

## 7. 技术方案
- Manifest V3，一套代码同时发布 Chrome 与 Edge。
- 框架：WXT + TypeScript + Vite；UI 用 React + Kumo【已定】。
- 权限：`bookmarks`、`storage`、`unlimitedStorage`、`favicon`、`identity`、`alarms`（定时同步）；host 权限 `https://www.googleapis.com/*`。
- favicon：浏览器 `_favicon` API，本地缓存。
- 测试：Vitest 单测（拍平、命名回退、去重、分身、循环挂载检测、同步合并）；Playwright 加载扩展做 E2E。
- 隐私：数据仅在本地与用户自己的 Drive，不收集任何统计。
