# Navill 产品说明

> 由 [PLAN.md](PLAN.md) 提炼的产品边界；细节与未决项以 PLAN 为准。

## 一句话
给书签多、浏览器书签栏已经乱掉的人：把书签一次性导入，按「工作区 → 抽屉 → 书签」重新整理，打开新标签页就能用。

## 用户与权限
- 公开扩展，无账号体系；Google 账号只用于把数据同步到用户自己的 Drive `appDataFolder`（`drive.appdata` scope）。
- 不收集任何数据。

## MVP（M1–M5）
- 首次导入：Edge 工作区节点 → 工作区；书签栏顶级文件夹 → 工作区；嵌套文件夹拍平为抽屉；散放书签进「待整理」。
- 新标签页 + 弹窗：浏览、搜索、拖拽、增删改、「整理」多选批量移动 / 创建分身。
- 抽屉：改名、创建分身、解散、删除、打乱；排序与四种视图（图标 / 行 / 平铺 / bento）。
- 书签：名称、URL、图标、备注、打开次数与每次时间戳。
- 分身、分身书签组（防循环挂载）、管理页。
- 设置、导入导出（JSON / HTML）、重新导入。
- Google Drive 同步：本地优先 + Outbox + 15 分钟批量。

## 以后再做
- AI 自动分类、书签内容抓取。

## 不做
- 与浏览器书签双向同步、标签页 / 会话管理、侧边栏。

## 设计
- Kumo 设计系统，phosphor 图标，明暗主题跟随系统，中文 UI。
