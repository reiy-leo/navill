# Search and Shortcuts

| Action | Shortcut |
| --- | --- |
| Open search | `/` or ⌘L (Ctrl+L) |
| Search from the address bar | type `nv`, a space, then your keywords |
| Filter by tag | type `#` and the tag name in search, such as `#To-do` |
| Open in a background tab | ⌘-click (Ctrl-click) or middle-click |
| Sync now | ⌘S (Ctrl+S) |

Search matches titles, URLs, notes and related links, and you can use it entirely from the keyboard: arrow keys to move, Enter to open.

When the address bar has focus, ⌘L belongs to the browser; click the page first. ⌘S is skipped (with a notice) if you synced less than 3 minutes ago or nothing has changed.

Settings → Keys lists all shortcuts.
