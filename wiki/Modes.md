# Modes

A **mode** decides which workspaces and drawers are visible, so you only see what you need right now. Presets: Default, Work, Home, Talk and Lend.

- Switch modes from the switcher at the bottom of the new tab page or in the toolbar popup. Each device remembers its own current mode.
- Edit modes in Settings → Modes: tick the workspaces and drawers each mode shows. Hiding a workspace hides its drawers too.
- **Default** always shows everything and can't be renamed or deleted.
- Each mode has a **Show 18+ content** switch. When it's off, 18+ workspaces, drawers and bookmarks tagged 18+ are hidden.
- Search, the popup and "open all" only cover what the current mode shows.
- When you create a workspace or drawer outside Default, Navill asks whether it should appear in this mode only or in all modes.
