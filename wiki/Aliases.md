# Aliases

An **alias** puts the same bookmark in another drawer or workspace. It's a reference, not a copy: editing the original changes every alias, and open counts are shared.

- Right-click a bookmark → **Alias to…**, then pick a workspace and drawer.
- Aliases carry a small badge; hover it to see where the original lives.
- Deleting the original asks whether to delete only this one or the original and all its aliases. Deleting an alias only removes that spot.

## Alias groups

An **alias group** mounts all bookmarks of one drawer into another drawer, even in another workspace. New bookmarks in the source show up in the target right away. Navill refuses mounts that would loop (A → B → A).

Create one from a drawer's ⋯ menu. **Aliases** in the ⋯ menu opens Manage aliases, which lists every alias and alias group; there you can **Make independent** to turn an alias into its own bookmark.
