# 安装

| 浏览器 | 去哪装 |
| --- | --- |
| Chrome 及其他 Chromium 浏览器 | [Chrome 应用商店](https://chromewebstore.google.com/detail/navill/lphobabkijoeabbjphfafflimnjgpdfb) |
| Microsoft Edge | Edge 加载项商店（搜 Navill），也可以从 Chrome 应用商店装 |
| Firefox 140 及以上 | [Firefox 附加组件](https://addons.mozilla.org/zh-CN/firefox/addon/navill/) |

装好后打开新标签页，Navill 会接管新标签页，先显示欢迎页。

## 手动装测试版

每个版本（包括 alpha）都在 [GitHub Releases](https://github.com/reiy-leo/navill/releases)，文件是 `navill-<版本>-chrome.zip`、`-edge.zip`、`-firefox.zip`。

1. 下载对应浏览器的包，解压。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选解压出来的文件夹。

手动装的版本和商店版扩展 ID 不同，数据各存各的。想把数据搬过去，用 [[同步]] 或 [[导入与导出]]。

## Firefox 说明

- 需要 Firefox 140 或更新。
- 导入时 Firefox 会问一次是否允许读取书签。
- Firefox 没有自带的网站图标接口，图标改从 Google 的图标服务取。
