# 隐私与权限

Navill 不收集任何数据。书签存在浏览器里；开了同步的话，也存在你自己的 Google Drive 或 WebDAV。完整的隐私政策：[https://navill.rei8t.dev/privacy](https://navill.rei8t.dev/privacy)。

| 权限 | 用来做什么 |
| --- | --- |
| bookmarks | 导入时读取浏览器书签 |
| storage、unlimitedStorage | 在浏览器里保存数据 |
| favicon（Firefox 没有） | 显示网站图标 |
| identity | 登录 Google，用于同步和分享 |
| alarms | 定时同步 |
| googleapis.com | Google Drive 同步 |
| icon.horse、google.com/s2、gstatic.com | 获取高清网站图标 |
| navill.rei8t.dev | 分享和市场 |
| history（可选） | 添加书签时给出建议 |
| 访问所有网站（可选） | 从网站本身取图标；连接你的 WebDAV 服务器 |
