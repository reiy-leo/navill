# 构建与开发

需要 Node 22+ 和 pnpm 10+。

```bash
pnpm install
pnpm dev           # 开发模式，热更新
pnpm build         # Chrome  → .output/chrome-mv3
pnpm build:edge    # Edge    → .output/edge-mv3
pnpm zip           # 打商店用的 zip（另有 zip:edge、zip:firefox）
pnpm compile       # 类型检查
pnpm test          # 单元测试
```

打开 `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序，选构建出来的目录。

## 用自己的 OAuth 客户端同步 Google Drive

构建默认内置正式客户端 ID。自己 fork 时：

1. 在 Google Cloud Console 新建 OAuth 客户端，类型选「Web 应用」，启用 Google Drive API，同意屏幕只加 `drive.appdata`。
2. 每个浏览器各加一个重定向 URI：`https://<扩展 ID>.chromiumapp.org/`。设置 → 同步 页会显示本机的回调地址。
3. 复制 `.env.example` 为 `.env`，填 `WXT_GOOGLE_CLIENT_ID`。想固定扩展 ID，再填 `WXT_EXTENSION_KEY`。
4. 重新 `pnpm build`。

## 翻译

界面源文是中文，`src/i18n/*.json` 里有英语、西班牙语、葡萄牙语（巴西）、俄语、日语、德语、法语、印尼语。每加一条文案都要补齐这 8 个文件，`pnpm test` 会检查 key 和占位符。

## 发版

推版本 tag 会构建 Chrome、Edge、Firefox 三个包并创建 GitHub Release。正式版会自动提交到 Chrome 应用商店、Edge 加载项和 Firefox 附加组件。
