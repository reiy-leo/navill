# Import and Export

Settings → Data:

- **Export** a Navill JSON backup (everything, including aliases, modes and tags), or a standard bookmarks HTML file that any browser can import. Related links become ordinary bookmarks in the HTML file.
- **Import** a Navill JSON backup or a bookmarks HTML file.
- **Re-import** from the browser: appends and skips URLs you already have. You can also replace existing data instead; Navill confirms first and downloads a backup.
