# Bookmarks

Right-click a bookmark for: Edit, Tags…, Alias to…, Move, Archive, Delete.

- **Edit**: name, URL, icon, note and related links. While you type a name or URL, Navill can suggest pages from your browsing history (it asks for the optional *history* permission the first time).
- **Related links**: extra links for one bookmark, such as its GitHub page or docs. A small red dot on the icon means it has some; click it to see the list.
- **Tags**: a bookmark can have several tags. Three are built in: 18+, Favorites and To-do. Add your own in Settings → Tags.
- **Favorite**: hover a bookmark and click the star. Favorites show up on Home.
- **Open count**: Navill counts every time you open a bookmark from it, and uses that for sorting and "Most used".

## Organize mode

Choose **Organize** in the ⋯ menu to select bookmarks across workspaces and drawers, then move them, alias them, or tag them all at once.

## Opening bookmarks

Click to open (in the current tab, a new tab or the background — see Settings → General). Hold ⌘ (Ctrl on Windows and Linux) or use the middle mouse button to open in a background tab.

## HD site icons

Navill fetches a sharper icon for each site and keeps it on this device only. To use icons from the sites themselves, allow the optional "access all sites" permission in Settings → General. **Refetch** clears the cache.
